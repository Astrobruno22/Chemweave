# ChemWeave

ChemWeave is a research project for reducing astrochemical reaction networks in models of protoplanetary disks. It uses graph-based analysis to identify the chemical species and reactions that are most important to a chosen scientific problem, with the goal of producing smaller networks that retain the essential chemistry of the original model.

## Project Goals

- Represent astrochemical reaction networks as graphs.
- Identify influential species, reactions, and chemical pathways.
- Reduce network size while preserving scientifically relevant behavior.
- Compare reduced networks with the original chemical network.
- Improve the computational efficiency and interpretability of protoplanetary-disk chemistry models.

## Repository Structure

- `Network.py`, tools for constructing and analyzing the chemical network.
- `model.py`, model setup and chemical-network calculations.
- `rate.py`, reaction-rate calculations.
- `.gitignore`, files and folders excluded from version control.

Additional documentation, reaction data, species data, and analysis scripts will be added as the project develops.

## Project Status
